# Keyboard shortcuts

[Türkçe](keyboard-shortcuts.tr.md)

Yalqen is keyboard-first. These are the macOS shortcuts in the current build, grouped by area. Every action is also available from the menu bar or the command bar.

## Tabs

| Action                 | Shortcut |
| ---------------------- | -------- |
| New tab                | ⌘T       |
| Close tab              | ⌘W       |
| Reopen closed tab      | ⇧⌘T      |
| Next tab               | ⌃Tab     |
| Previous tab           | ⌃⇧Tab    |
| Go to tab 1–8          | ⌘1–⌘8    |
| Go to last tab         | ⌘9       |
| Bookmark or unbookmark | ⌘D       |
| Show all bookmarks     | ⌥⌘B      |

## Navigation

| Action                         | Shortcut |
| ------------------------------ | -------- |
| Open the command bar (address) | ⌘L       |
| Reload                         | ⌘R       |
| Reload ignoring the cache      | ⇧⌘R      |
| Stop loading                   | Esc      |
| Find in page                   | ⌘F       |
| Find next                      | ⌘G       |
| Find previous                  | ⇧⌘G      |

## Command bar and find bar

| Action                          | Shortcut |
| ------------------------------- | -------- |
| Move through suggestions        | ↑ ↓      |
| Run the selected item or submit | Return   |
| Close the command bar           | Esc      |
| Next match (find bar)           | Return   |
| Previous match (find bar)       | ⇧Return  |
| Close the find bar              | Esc      |

## Page

| Action                | Shortcut |
| --------------------- | -------- |
| Zoom in               | ⌘+ or ⌘= |
| Zoom out              | ⌘-       |
| Reset zoom            | ⌘0       |
| Save as PDF           | ⇧⌘S      |
| Print                 | ⌘P       |
| Undo                  | ⌘Z       |
| Redo                  | ⇧⌘Z      |
| Cut                   | ⌘X       |
| Copy                  | ⌘C       |
| Paste                 | ⌘V       |
| Paste and match style | ⌥⇧⌘V     |
| Select all            | ⌘A       |

## Developer tools

| Action                      | Shortcut |
| --------------------------- | -------- |
| Toggle page developer tools | ⌥⌘I      |
| View page source            | ⌥⌘U      |
| Toggle phone view           | ⌥⌘M      |
| Rotate device               | ⇧⌥⌘M     |
| Select element for agent    | ⌥⌘P      |
| Show or hide AI panel       | ⌥⌘A      |

While phone view is on, focus the resize handle of the responsive frame and use the arrow keys to resize it, or hold ⇧ for larger steps.

## Window and app

| Action                       | Shortcut |
| ---------------------------- | -------- |
| New window                   | ⌘N       |
| New private window           | ⇧⌘N      |
| Close window                 | ⇧⌘W      |
| Collapse or expand tab panel | ⌘S       |
| Show or hide top bar         | ⇧⌘B      |
| Show or hide sidebar         | ⇧⌘U      |
| Settings                     | ⌘,       |
| Hide Yalqen                  | ⌘H       |
| Hide others                  | ⌥⌘H      |
| Quit Yalqen                  | ⌘Q       |

## Menu-only actions

These have no shortcut: new private tab, new developer window and move tab to a new window (File and Tab menus). Screenshot, full-page screenshot, toggle cache, auto reload and device selection are in the View and File menus, and can also be run from the command bar by name.
