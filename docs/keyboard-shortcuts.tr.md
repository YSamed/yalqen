# Klavye kısayolları

[English](keyboard-shortcuts.md)

Yalqen klavye öncelikli çalışır. Aşağıda güncel sürümdeki macOS kısayolları alanlara göre gruplanmıştır. Her eyleme menü çubuğundan veya komut çubuğundan da ulaşılabilir.

## Sekmeler

| Eylem                        | Kısayol |
| ---------------------------- | ------- |
| Yeni sekme                   | ⌘T      |
| Sekmeyi kapat                | ⌘W      |
| Kapatılan sekmeyi yeniden aç | ⇧⌘T     |
| Sonraki sekme                | ⌃Tab    |
| Önceki sekme                 | ⌃⇧Tab   |
| 1–8. sekmeye git             | ⌘1–⌘8   |
| Son sekmeye git              | ⌘9      |
| Yer imine ekle/kaldır        | ⌘D      |
| Tüm yer imlerini göster      | ⌥⌘B     |

## Gezinme

| Eylem                        | Kısayol |
| ---------------------------- | ------- |
| Komut çubuğunu (adres) aç    | ⌘L      |
| Yenile                       | ⌘R      |
| Önbelleği yok sayarak yenile | ⇧⌘R     |
| Yüklemeyi durdur             | Esc     |
| Sayfada bul                  | ⌘F      |
| Sonrakini bul                | ⌘G      |
| Öncekini bul                 | ⇧⌘G     |

## Komut çubuğu ve bulma çubuğu

| Eylem                             | Kısayol |
| --------------------------------- | ------- |
| Öneriler arasında gez             | ↑ ↓     |
| Seçili öğeyi çalıştır veya gönder | Return  |
| Komut çubuğunu kapat              | Esc     |
| Sonraki eşleşme (bulma çubuğu)    | Return  |
| Önceki eşleşme (bulma çubuğu)     | ⇧Return |
| Bulma çubuğunu kapat              | Esc     |

## Sayfa

| Eylem                    | Kısayol    |
| ------------------------ | ---------- |
| Yakınlaştır              | ⌘+ veya ⌘= |
| Uzaklaştır               | ⌘-         |
| Varsayılan boyut         | ⌘0         |
| PDF olarak kaydet        | ⇧⌘S        |
| Yazdır                   | ⌘P         |
| Geri al                  | ⌘Z         |
| Yinele                   | ⇧⌘Z        |
| Kes                      | ⌘X         |
| Kopyala                  | ⌘C         |
| Yapıştır                 | ⌘V         |
| Stili eşleyerek yapıştır | ⌥⇧⌘V       |
| Tümünü seç               | ⌘A         |

## Geliştirici araçları

| Eylem                                 | Kısayol |
| ------------------------------------- | ------- |
| Sayfa geliştirici araçlarını aç/kapat | ⌥⌘I     |
| Sayfa kaynağı                         | ⌥⌘U     |
| Telefon görünümünü aç/kapat           | ⌥⌘M     |
| Cihazı döndür                         | ⇧⌥⌘M    |
| Ajan için öğe seç                     | ⌥⌘P     |
| Yapay zekâ panelini aç/kapat           | ⌥⌘A     |

Telefon görünümü açıkken, yeniden boyutlandırma tutamacına odaklanıp ok tuşlarıyla çerçeveyi boyutlandırabilirsin. Daha büyük adımlar için ⇧ tuşunu basılı tut.

## Pencere ve uygulama

| Eylem                          | Kısayol |
| ------------------------------ | ------- |
| Yeni pencere                   | ⌘N      |
| Yeni gizli pencere             | ⇧⌘N     |
| Pencereyi kapat                | ⇧⌘W     |
| Sekme panelini daralt/genişlet | ⌘S      |
| Üst menüyü göster/gizle        | ⇧⌘B     |
| Yan menüyü göster/gizle        | ⇧⌘U     |
| Ayarlar                        | ⌘,      |
| Yalqen'i gizle                 | ⌘H      |
| Diğerlerini gizle              | ⌥⌘H     |
| Yalqen'den çık                 | ⌘Q      |

## Yalnızca menüden erişilen eylemler

Bunların kısayolu yoktur: yeni gizli sekme, yeni geliştirici penceresi ve sekmeyi yeni pencereye taşıma (Dosya ve Sekme menüleri). Ekran görüntüsü, tam sayfa ekran görüntüsü, önbelleği aç/kapat, otomatik yenileme ve cihaz seçimi Görünüm ve Dosya menülerindedir; komut çubuğundan adıyla da çalıştırılabilir.
