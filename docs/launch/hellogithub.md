## 项目描述

```
Yalqen 是基于 Chromium 的 macOS 开源浏览器（MIT），用垂直标签页和命令栏取代传统工具栏，内置广告与跟踪器拦截、仅 HTTPS、安全 DNS 和开发者工具，让界面少占空间，键盘即可完成大部分操作。
```

## 亮点

```
1. 垂直标签页：固定标签、地址栏和窗口控制集中在一个窄面板里，内容区更大
2. 命令栏：打开标签页、搜索、跳转、执行操作全程键盘完成
3. 内置广告和跟踪器拦截，另有第三方 Cookie 拦截、仅 HTTPS 模式和安全 DNS，无需安装扩展
4. 内置 Chromium DevTools，一键切换手机视图并带设备预设，适合调试响应式页面
5. 内存节省：自动卸载闲置标签页，同时兼容 Chrome 应用商店扩展
6. 已签名并公证，支持自动更新，可用 Homebrew 一行命令安装
```
