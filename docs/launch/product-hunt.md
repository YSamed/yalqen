## Description (max 260 characters)

```
Yalqen is a free, open-source Chromium browser for macOS built for developers. Vertical tabs, a keyboard-first command bar, one-key phone view and DevTools, and ad and tracker blocking built in. Signed, notarized and self-updating.
```

## Maker's first comment

```
Hey Product Hunt 👋 I'm Yaşar, the maker of Yalqen.

I spend most of my day in a browser, switching between docs, localhost and DevTools. I wanted something that stays out of the way: tabs in a vertical panel, every action in a command bar, a phone view on one key for responsive testing, and no ads or trackers without installing anything.

Yalqen is open source under MIT, runs on Apple Silicon Macs with macOS 13+, and updates itself with your tabs restored.

It's built on Electron. I wrote honestly about what that costs: https://github.com/YSamed/yalqen/blob/main/docs/why-electron.md

I'd love to hear what would make it your daily browser.
```
