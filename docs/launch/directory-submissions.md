Long description:

```
Yalqen is a free, open-source Chromium browser for macOS built for developers.

Tabs live in a vertical panel, and every action is one keystroke away in a command bar that also searches your open tabs. Press one key for a phone view to test responsive layouts, and dock Chromium DevTools beside the page. Ads and trackers are blocked out of the box, with no extension to install. Chrome Web Store extensions are supported.

It is signed, notarized and updates itself, restoring your tabs. MIT licensed, for Apple Silicon Macs on macOS 13 or later. Install with Homebrew or a direct download.
```

Use cases (for forms that ask):

```
- Switching between docs, localhost and DevTools without losing tabs
- Testing responsive layouts in a phone view
- Keyboard-driven browsing for people who live in the terminal
- Browsing without ads and trackers, with no extra setup
```
