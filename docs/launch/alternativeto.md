> Open-source Chromium browser for developers on macOS, with vertical tabs, a keyboard-first command bar and built-in ad blocking.

**Long description:**

> Yalqen is a free, open-source web browser for macOS built for developers. It keeps tabs, the address bar and window controls in one vertical panel, and puts every action behind a keyboard-first command bar.
>
> Ad and tracker blocking, third-party cookie blocking, HTTPS-only mode and secure DNS are built in and on by default. Developer tools and a one-key phone view with iPhone, Pixel, Galaxy and iPad presets are always a shortcut away. A memory saver discards tabs you have not looked at for a while and brings them back when you return.
>
> Yalqen installs extensions from the Chrome Web Store, saves and autofills passwords, translates pages, and updates itself in the background with your tabs restored. It is signed and notarized by Apple and released under the MIT license.
