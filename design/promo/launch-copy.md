## Hacker News

Title: Show HN: Yalqen – An open-source Chromium browser for developers on macOS

URL: https://yalqen.com/

Maker comment:

Hi HN, I built Yalqen, a free, MIT-licensed Chromium browser for developers on macOS, using Electron and TypeScript.

It combines vertical tabs and a keyboard-first command bar with Chromium DevTools, request rules, network throttling, and a phone view for responsive testing. It also includes built-in ad and tracker blocking.

It requires macOS 13 or later on Apple Silicon. You can download a signed and notarized build from the website or install it with `brew install --cask YSamed/yalqen/yalqen`.

Source: https://github.com/YSamed/yalqen

I'd appreciate feedback on the keyboard workflow and developer tools, and I'm happy to discuss implementation tradeoffs.
